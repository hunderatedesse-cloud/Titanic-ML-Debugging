# Titanic ML Debugging

A beginner machine learning project for predicting Titanic passenger survival using Logistic Regression.

## Machine Learning Type

- Supervised Learning
- Binary Classification

## Algorithm

Logistic Regression

## Dataset

Titanic dataset from Kaggle.

## Workflow

1. Load the dataset
2. Explore the dataset
3. Handle missing values
4. Select features
5. Encode categorical variables
6. Split data into training and testing sets
7. Train Logistic Regression
8. Make predictions
9. Evaluate the model
10. Analyze the confusion matrix

## Features

The model uses:

- Pclass
- Sex
- Age
- SibSp
- Parch
- Fare
- Embarked
